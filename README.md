# Нуриев Арслан — личный сайт десятиклассника

Сайт ученика 10 класса о подготовке к ЕГЭ по истории, английскому языку и обществознанию, а также сравнительная таблица нейросетей.

**Автор — Нуриев Арслан.**

## Страницы

- **Обо мне** (`/`) — знакомство, гуманитарный маршрут, предметы, принципы подготовки и план на 10–11 класс.
- **Предметы ЕГЭ** (`/subjects`) — три предмета с темами и фокусом, ресурсы, недельный ритм и интерактивные чек-листы с прогрессом.
- **Нейросети** (`/ai`) — сравнительная таблица шести сервисов: возможности, тарифы, преимущества, недостатки и ссылки.

## Запуск

```bash
npm install
npm run dev
```

Открыть сайт: адрес из вывода Vite (обычно `http://localhost:5173`).

Сборка для публикации:

```bash
npm run build
npm run preview
```

Готовая сборка лежит в `dist/`.

## Что можно поменять

- Текст профиля, предметы, темы, цели, пункты чек-листа и таблица нейросетей — в `src/data/content.js`.
- Общие стили — в `src/styles.css`.
- Заголовок и описание сайта — в `index.html`.
- Прогресс чек-листа хранится в `localStorage` под ключом `arslan-ege-progress-v1`. Его можно сбросить кнопкой на странице «Предметы ЕГЭ».

## Технологии

React 18, React Router (HashRouter), Vite, чистый CSS. Прогресс чек-листа сохраняется локально в браузере.
